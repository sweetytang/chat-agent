# LUI Agent 前端视觉与交互深度升级

## 目标

在不改变后端协议和既有业务能力的前提下，对 `apps/lui-agent/frontend` 的呈现层进行深度升级，使其达到现代 AI 对话产品的视觉与交互质量：浅色主题借鉴 ChatGPT/Claude 的克制、留白和阅读体验，深色主题借鉴 Gemini 的炭黑、靛蓝和柔和光晕，同时形成独立的 LUI Agent 品牌表达。

用户价值：界面层级更清晰、长内容更易读、状态反馈更明确、桌面与移动端体验一致，且登录、线程、流式运行、工具审核、checkpoint 分支、结构化输出和生成式 UI 等现有能力继续可用。

## 已确认事实

- 前端技术栈为 React 19、TypeScript、Vite、Zustand、CSS Modules。
- 现有认证 Store 只保存 access token 和错误，不保存邮箱或用户资料。
- 线程列表使用真实后端数据，`ThreadSummary` 没有创建时间或更新时间，因此不能可靠按“今天 / 更早”分组。
- 当前结构化输出和生成式 UI 在 Run Store 中是单值状态；若要按事件顺序展示多个结果，需要扩展前端展示模型，但后端协议保持不变。
- 现有聊天、鉴权、线程、分支、审核、结构化输出、生成式 UI 和 SSE 数据流必须保留。
- 项目已经配置 ESLint、TypeScript ESLint、Stylelint 和 Prettier。

## 范围内需求

### 1. 主题与品牌

- 支持 `light`、`dark`、`system` 三档主题，默认 `system`。
- 主题选择即时生效并保存到 `localStorage`；`system` 模式响应系统主题变化。
- 浅色主题使用暖白/中性灰与蓝紫强调色；深色主题使用炭黑与靛蓝/紫色柔光。
- 颜色、间距、圆角、阴影、动效等通过全局 Design Tokens 管理，组件禁止散落硬编码主题色。
- 创建由两个交叠圆角几何形组成的品牌标识；浅色使用靛蓝 + 天蓝，深色使用靛蓝 + 紫色。
- 同一标识复用于主区域顶栏、移动端抽屉和 SVG favicon。

### 2. 应用框架与侧边栏

- 顶栏左侧显示品牌标识和 `LUI Agent`、侧边栏切换按钮；右侧显示主题菜单。
- 桌面侧边栏支持展开和折叠；折叠后保留窄图标栏、新建会话和展开按钮。
- 侧边栏包含新建会话、会话搜索、真实会话列表和用户区域。
- 会话标题单行省略，不按日期分组；列表区域独立滚动。
- 登录且无会话时显示空状态和新建会话入口。
- 未登录时隐藏会话列表，在底部显示“登录 / 注册”入口。
- 手机和平板窄屏使用左侧抽屉、半透明遮罩和页面滚动锁定；点击遮罩、选择会话或切换按钮关闭。

### 3. 认证呈现

- 未登录时不在聊天主区域展示现有认证面板。
- 侧边栏底部登录入口打开 Radix Dialog，默认登录，可切换注册。
- Dialog 支持关闭按钮、遮罩点击和 `Esc` 关闭，并采用 Radix 默认焦点管理。
- 表单只有登录或注册成功后才清空；普通关闭保留内容。
- 未登录时主区域显示登录引导，隐藏快捷提示，输入框整体禁用。
- 登录后用户区显示头像/首字母、邮箱或可用的身份退化文案和账户状态；账户菜单提供退出登录。
- 在不改后端协议的前提下，邮箱可由成功登录/注册时输入的邮箱保存到前端会话状态。

### 4. 欢迎页与快捷提示

- 登录且当前会话没有消息时，显示品牌标题、简短副标题、大输入框和 4 个快捷提示。
- 快捷提示兼顾 Agent 能力与通用聊天：代码分析、结构化整理、执行计划、文本总结。
- 点击快捷提示只填充输入框并聚焦，不自动发送。
- 未登录欢迎页只显示品牌与登录引导，不显示快捷提示。

### 5. 消息与内容阅读

- 用户消息使用右侧浅靛蓝/深蓝灰气泡；助手消息使用左侧无大面积气泡的文档式内容。
- 助手内容最大宽度约 `760px`，用户消息最大宽度约 `680px`，长内容自动换行。
- 保留编辑、重新生成、分支切换等现有操作。
- 优化 Markdown 的标题、段落、列表、引用、链接、表格和代码样式。
- 表格支持横向滚动；代码块支持复制，复制成功反馈约 1.5 秒后恢复。
- 工具、审核、结构化输出、生成式 UI 和错误结果使用独立卡片与轻量类型强调色。
- 结果卡片按事件发生顺序进入消息流；结构化输出和生成式 UI 默认展开，可在当前页面内折叠。

### 6. 输入、运行与错误反馈

- 输入框支持多行、自动高度、`Enter` 发送、`Shift+Enter` 换行；中文输入法组合输入期间不得发送。
- 运行中发送按钮切换为停止按钮；点击后立即终止本地 SSE 并调用后端取消接口。
- 流式运行显示渐进内容和轻量等待状态。
- 错误以内联状态卡展示；记录最近一次运行参数，允许重新发起相同请求。
- 输入区和消息流在移动端不得互相遮挡。

### 7. 组件与交互技术约束

- 图标使用 `lucide-react`，品牌 Logo 后续可独立迭代。
- 可按需使用 Radix Primitives；不引入 Radix Themes，所有视觉样式完全自定义。
- 优先使用 Radix 提供的键盘、焦点、遮罩和弹层无障碍能力。
- 动画保持克制，并支持 `prefers-reduced-motion`。
- 所有界面文案使用中文。
- 组件与对应 `index.module.css` 放在同一目录；全局主题变量只放在应用全局样式。

## 范围外

- 不复制 Gemini、ChatGPT 或 Claude 的品牌资产、Logo、文案或像素级布局。
- 不修改 FastAPI 路由、SSE 事件协议、数据库模型或后端业务逻辑。
- 不伪造会话列表数据，不按缺失的时间字段做日期分组。
- 不新增文件上传、语音输入、模型选择或账户设置后端能力。
- 不引入 Radix Themes 或其他成套视觉主题库。
- 不在本任务中重新设计 structured output / generative UI 的后端事件身份协议。

## 验收标准

- [ ] 首次访问默认跟随系统主题，用户可在右上角选择浅色、深色或跟随系统，刷新后保留偏好。
- [ ] 浅色与深色主题覆盖页面、侧边栏、弹层、消息、输入框、代码块和结果卡片，无明显硬编码色遗漏。
- [ ] 桌面侧边栏可展开/折叠；手机侧边栏以带遮罩抽屉打开，打开时主页面滚动锁定。
- [ ] 未登录时会话列表和快捷提示隐藏，输入框禁用，登录入口可打开并关闭认证 Dialog。
- [ ] 登录/注册功能、错误提示、表单切换和退出登录保持可用；表单只在成功后清空。
- [ ] 登录且无消息时显示欢迎页与 4 个快捷提示，点击后填入并聚焦输入框但不自动发送。
- [ ] 输入框支持自动高度、Enter 发送、Shift+Enter 换行和中文输入法保护。
- [ ] 用户消息和助手消息符合已确认的气泡/文档流布局，长 Markdown、代码块和表格可读。
- [ ] 代码块复制后显示短暂成功反馈。
- [ ] 工具审核、checkpoint 分支、结构化输出和生成式 UI 既有功能可继续操作。
- [ ] 运行中发送按钮变为停止按钮，停止同时终止本地 SSE 并请求后端取消。
- [ ] 错误以内联卡片显示，并可按最近一次请求参数重试。
- [ ] 结构化输出与生成式 UI 卡片默认展开且可折叠；多个展示结果不会互相覆盖。
- [ ] `pnpm format:check`、`pnpm lint`、`pnpm build` 和 `pnpm test` 全部通过。
- [ ] 使用真实浏览器验证桌面浅色、桌面深色、移动端未登录和移动端已登录四个关键视图。
