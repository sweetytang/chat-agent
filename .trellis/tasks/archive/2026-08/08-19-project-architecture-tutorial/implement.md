# 教程产出计划

## 顺序

1. 汇总仓库结构、启动命令和入口文件。
2. 绘制简化架构关系与状态归属说明。
3. 按普通消息链路解释前端、SSE、API、运行时、模型和持久化。
4. 补充事件协议、时间线、checkpoint 分支和特殊运行流程。
5. 补充 MCP、鉴权、类型生成、测试与源码阅读路线。
6. 用文件路径和当前代码核对所有关键事实，避免把未实现内容写入教程。

## 验证

- `make help`、`Makefile`、`compose.yml` 与启动说明一致。
- 关键入口通过 `rg` 和带行号的源码检查。
- 教程提及的测试命令与 `Makefile`、前后端 package 配置一致。
- 不修改产品代码，不新增用户文档。

## 交付形式

在对话中直接交付中文教程；不在仓库创建额外教程文档。
